## 为什么官方搜索搜不到中文频道

Telegram 自带搜索对中文公开内容收录和匹配很弱：输入中文关键词，经常搜不到已经存在的公开频道和群组。常用补法是用 Telegram 里的搜索机器人查它们收录的公开内容索引，其中用得最多的是极搜（Jisou）——不用装新 App、不用网页注册，在 Telegram 里打开机器人发关键词就能搜。

## 关键词技巧

- 用主题词不用整句话：搜「Python 学习」比搜一整句问话准。
- 中英文各试一次：很多中文频道名带英文（AI、Open Source、Remote Jobs），结果不一样。
- 换同义词多试几轮：如「课程 / 教程 / 学习资料」。
- 搜不到就缩小范围：不搜「资源」这种大词，改搜「电子书」「公开课」「开源项目」这类具体公开内容。

## 能搜什么、不能搜什么

- **能搜**：已被收录的公开频道、公开群组和机器人（新闻资讯、开源社区、学习交流、工具导航等）。
- **搜不到**：私密群组、未被收录的新频道、私聊内容。声称能搜私密内容或他人聊天记录的是骗子。
- **边界**：只用它查找正规主题的公开社群；不要用它找盗版、破解、色情、赌博类内容，那类结果也是诈骗和恶意文件的高发区。

## 安全清单

- **核用户名**：仿冒频道常用形近字符改字母，别只看头像和名称。
- **看历史**：正规频道有连续历史内容；全是转账截图和“高收益包赚”骗局话术的直接退出。
- **不交敏感信息**：索要账号密码、短信验证码、钱包助记词的立即停止。
- **不先付钱**：搜索结果是第三方公开内容，付费前先找其他平台的官方出处交叉核对。
- **文件先杀毒**：陌生群下载的安装包、脚本不要直接运行。
